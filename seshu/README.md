# Moka Seshu — Portfolio

Live: https://mokaseshu.github.io/MOKA/seshu/

3D glass portfolio with every build so far: client sites, own products and the full RootFix archive.

- `index.html` — the whole site (Three.js glass hero, GSAP, Lenis)
- `assets/logo-mark.svg`, `assets/logo-full.svg` — MS logo
- `assets/avatar.jpg` — profile photo (add it and it shows automatically)

- `assets/work/` — extra desktop/phone screenshots for the Selected work mockups

Media is shared from `../rootfix/assets/` and `../portfolio/media/`.

To feature a different project, edit the `FEATS` list in `index.html` (slug, phone screenshot, accent colour, stack chips).
