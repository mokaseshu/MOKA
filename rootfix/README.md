# RootFix website

Static site. Open `index.html`, or deploy the folder to GitHub Pages or Netlify as it is.

- `index.html` home page
- `work/` case file index and one page per case
- `assets/work/` screen recordings (MP4, WebM, poster JPG)
- `assets/img/` marketing pages and the report cover
- `assets/brand/` logo and root textures
- `css/style.css`, `js/main.js`
